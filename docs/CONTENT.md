## 4. 木屋工坊 / 锻造屋（Crafted Items）叙事框架（待落地 · V7 Task 28）
将研究项目与工程开发包装为工坊代表作，摒弃冷冰冰的论文摘要叙事：
- **锻造代表作一：rpcsim 纳秒显式计费调度仿真器**
  - *工坊寄语*：128 核高并发世界的“瑞士钟表”。
  - *为什么造这个轮子*：“现有的网络级仿真器太重（跑一次几小时），单机多线程测试又受操作系统内核调度抖动干扰。我需要一台能把纳秒时间轴当尺子量、与排队论数学解析解 100% 对齐的显式计费引擎。”
  - *好玩的技术突破*：在无锁多队列环境下精确捕捉微秒任务窃取纠偏的时钟损耗，找到了 20% 算力预算下的最优调度相图。
- **锻造代表作二：my-ricardo 赛博木屋与随身工作台**
  - *工坊寄语*：一座零前端构建依赖的四季像素天地。
  - *为什么造这个轮子*：“厌倦了动辄成百上千兆 node_modules 和臃肿的打包工具，想给互联网留一间点开就能秒开、断网依然能看、连背景音乐都是浏览器即时算出来的干净小木屋。”
  - *好玩的技术突破*：Python 逐像素生成 56×32 地图底图与碰撞网格，Web Audio API 纯纯手算正弦与方波合成 4 首四季交响曲，4 倍超采样亚像素动画让像素在 120Hz 高刷屏上丝滑漫游。
