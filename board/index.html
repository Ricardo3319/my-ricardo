      有自建云端时，填主人口令就能把告示牌和暂存贴同步到服务器。

      没有云端时，仍可用 GitHub 钥匙：

      换了设备也想看到同一块告示牌，要一把钥匙：

      1. 在 GitHub 新建一个私有仓库，比如 board，建的时候勾上 README。
      2. 在 GitHub 的 Settings → Developer settings → Fine-grained tokens 里生成一把钥匙：只选这个仓库，权限只开 Contents 的读写。
      3. 每台设备都在下面填一次「用户名/仓库名」和这把钥匙。

      钥匙只存在这台设备的浏览器里。告示牌每改一次，仓库里就多一次提交，撕错了也找得回来。
