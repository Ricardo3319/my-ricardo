# DESIGN.md — 视觉、排印与音频设计规范

> **状态约定**：各节标题后缀标注实现状态（同 `docs/SPEC.md` 约定）。已实现为线上既有规范，待实现章节为 V7 规划，对应任务详见 `docs/progress.md`。

## 1. 整体视觉基调（已实现）
- **场景灵感**：俯视视角像素农场（受《星露谷物语》启发，非官方，与 ConcernedApe 无关）+ 复古木纹质感物品栏弹窗。
- **四季与昼夜系统**：`js/farm.js` 根据当前月份自动切换春/夏/秋/冬四张底图（`img/farm-*.png`），并根据本地时间叠加清晨、正午、黄昏、夜晚光影滤镜。

## 2. “外皮像素、内里现代”双轨排印层级（已实现）
为兼顾游戏沉浸感与高分屏长文可读性，全站严格区分两套字体变量：
- **游戏外壳层（`var(--font-pixel)`）**：`"Ark Pixel", monospace`，字号 `calc(12px * var(--px, 1))`。用于 HUD、导航栏、弹窗标题、按钮、NPC 对话框。
- **内容阅读层（`var(--font-sans)`）**：`system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`，字号 `clamp(14px, 1.02rem, 16px)`，行高 `1.75`。用于笔记正文、日常流水、关于列表、告示牌任务与剪贴板。

## 3. 阅读态背景遮罩与视觉聚焦（已实现）
- 当用户处于二级页面（弹窗面板打开状态）时，农场画布上方自动叠加 `.farm-backdrop-dim` 半透明暖黑遮罩（`background: rgba(18, 14, 10, 0.42); transition: opacity 0.25s ease;`），压低背景中草地与水池的高饱和度干扰，让视线聚焦于木框内的文字。
- 当用户关闭弹窗或在 `/` 首页操控小人漫游时，遮罩透明度降为 `0`。

## 4. 程序化音频系统（`js/sound.js`）（已实现）
- 零外部 MP3 资源依赖，使用 Web Audio API 实时合成 4 首田园曲目及风声、鸟鸣、虫鸣环境音，支持 IndexedDB 本地导入自定义曲目。

## 5. 首屏重心与生活化视觉规范（“欢迎来到我的赛博木屋”）（已实现 · V7 Task 28）
- **视觉重心转移**：首屏从“严谨学术履历”转向“数字领地与生活状态”，削弱论文感，强化松弛的个人表达。
- **生活化状态挂件（Now Widget）**：首屏顶部或木牌下方以动态卡片展现 Ricardo 此时此刻在木屋的生活动态：
  - 🎵 `最近在听`：随机/当前歌单（如田园八音盒 / 某首经典曲目）；
  - 🎮 `正在沉迷`：近期喜爱的独立游戏或像素游戏；
  - 🛠️ `折腾玩具`：当前手搓的原生 Web 工具、仿真脚本或硬件小玩意；
  - ☕ `今日状态`：手冲咖啡豆种、工作/学习状态与天气心情微标签。
- **人生装备栏 / EDC（Everyday Carry）RPG 属性卡**：
  - 扩充物品栏为玩家装备槽形式，展示主力机械键盘、降噪耳机、便携相机、精选书籍、手冲滤杯、游戏掌机等；
  - 鼠标悬浮（Hover）或触屏点击弹出复古像素羊皮纸 Tooltip，展现幽默属性词条（如“机械键盘：敲代码手速 +15%，深夜吵醒室友概率 +20%”）。
- **木屋工坊 / 锻造屋（Crafted Items）卡片**：
  - 针对 `rpcsim` 与 `my-ricardo` 代表作，摒弃标准论文摘要结构，以“工坊手造（Handcrafted）”视觉铭牌呈现；
  - 突出“造轮子动机”与“趣味技术攻坚节点”（如零依赖音频合成、4 倍超采样亚像素动画、128 核离散事件仿真器对齐过程）。

## 6. 环境音效与白噪音沉浸感设计（Web Audio 扩展）（已实现 · V7 Task 30）
- **昼夜节气白噪音体系**：
  - **夜间模式（Night）**：在既有虫鸣基础上，混入实时合成的松木篝火噼啪爆裂声（通过 Poisson 随机短脉冲搭配窄带带通滤波器模拟碳火微爆）；
  - **雨天/阴雨节气**：通过粉红噪声（Pink Noise）与双二阶滤波合成柔和雨滴声；
  - **四季微风动态**：随季节演进调节滤波截止频率与周期起伏包络。
- **番茄钟专注陪伴模式**：
  - 配合菜地番茄钟倒计时，提供轻量白噪音常驻后台挂机模式，使全站可作为沉浸式像素风工作白噪音工具。

## 7. 移动端触屏操控与视听引导（D-Pad & Sound Bubble）（已实现 · V7 Task 31）
- **虚拟十字键（Virtual D-Pad）**：
  - 移动端进入漫游模式时，在屏幕左下角展示半透明像素风四向控制盘（Opacity: 0.45，触碰时高亮至 0.8）；
  - 采用触控指针捕获（`setPointerCapture`），支持滑动连贯寻路，提升移动端与微信浏览器游玩舒适度。
- **声音呼吸小气泡（Audio Cue Bubble）**：
  - 首次进入农场且音频未开启时，在右上角 HUD 音量图标下方浮动呼吸小气泡（“🎵 点击开启声音”）；点击气泡开启现有田园环境音与音乐，其他交互只平滑淡出提示，记住已读状态；尊重系统减少动效设置。

## 8. 日常流水的图像表现与 Canvas 像素化滤镜（已实现 · V7 Task 34）
- **日常时间线微表情**：`/log/` 时间线卡片左侧增加心情与天气像素小图标（如 ☀️ 晴朗、🌧️ 细雨、☕ 咖啡、🌱 灵感）。
- **图片像素化双模滤镜**：
  - 在日常随笔与相册记录中，通过原生 Canvas 实现实时像素化（Downscale + Nearest-Neighbor Upscale）滤镜算法；
  - 访客点击图片可在一键切换“清爽原图”与“8-bit 像素艺术风预览”，兼顾真实感与赛博木屋复古基调。

## 9. 社交卡片与 Open Graph 视觉规范（已实现 · V7 Task 35）
- **社交分享封面图（og:image）**：
  - 统一采用 1200×630 分辨率的高清像素木屋夜景图（窗前暖灯、升腾炊烟、闪烁繁星与农场小溪）；
  - 确保微信好友卡片、飞书、Telegram 及 X/Twitter 抓取时呈现出别具一格的独立极客小木屋风貌。

## 10. 首页信息收敛（已实现 · V7 Task 36）
- 首屏只保留木屋身份叙事、单行近况、农场主入口及笔记/告示牌两个辅助入口；农场主入口横跨两列。
- 第二屏简短身份卡保留关于/联系，生活四格与工坊完整介绍使用原生 `details` 折叠，没开 JS 也能展开。
- 最新笔记与日常各一条精选预览，全部内容通过物理子页访问；游戏捷径折叠，移除重复农场入口卡。
- 暖木、纸色和现有风景保持一致，正文现代字体、农场交互像素字体；移动端单列阅读，不堆叠同权重卡片。
