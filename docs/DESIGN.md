# 外观

2026-10-02 重写，同日按本人意见改过一轮：右上角面板、季节自动、物品栏式内页、换页过渡、头像；同日加了告示牌。根目录旧的 `DESIGN.md`、`STYLE.md` 作废，要看去翻 git 历史。页面有哪些、放什么，看 `SPEC.md`。

## 1. 一句话

像在游戏里打开菜单：底下是俯视的农场，上面盖一层木框界面。首页是农场加一段对话，内页是浮在压暗农场上的物品栏式菜单。每页都是普通网址，能分享，不用走路。

## 2. 素材边界

可以用：

| 来源 | 许可 | 放在哪 |
| --- | --- | --- |
| Kenney Tiny Farm、Tiny Town 的 16px 图块 | CC0 | `tools/third-party/`，只给出图脚本读 |
| 方舟像素 12px，比例宽度，简中 | SIL OFL 1.1 | `fonts/` |
| `tools/art.py` 逐像素画的木框、图标、肖像、水面 | 本站 | 生成到 `img/` |

不可以用：

- 游戏的贴图、截图、字体、光标、音乐、角色、Logo、游戏名。粉丝站常用不等于有许可。
- 一比一复刻游戏 HUD：日晷时钟、金币栏、体力条、好感心心。本站右上角是自己设计的「一小块天」，不是日晷。
- 照着游戏截图吸色或描图。下面的颜色都是为本站另调的。

页面、`<title>`、站名、OG 里不出现游戏名、角色名、镇名。每页页脚有一行非官方声明。

## 3. 像素规则

- PNG 一律按 1 倍存。页面用 `--px` 整数倍放大：视口宽于 960px 时是 3，其余是 2。肖像另用 `--pp`，对应 3 和 2。
- 尺寸写成 `calc(N * var(--px))`，N 是美术像素数。像素图不用 `cover`、不用百分比缩放。
- 放大的图都加 `image-rendering: pixelated`。不加在 `body` 上。
- 木框一律用九宫格 `border-image`，角不拉伸。边的中段是纯色，所以 `stretch` 不会糊。
- 没有圆角，没有模糊阴影。字的阴影只用实色错位。

改图只改 `tools/art.py`，再跑 `python3 tools/art.py`。不要手改 `img/`。

## 4. 世界

`img/farm-<季节>.png`，56×32 格，每格 16 像素，合计 896×512。`.world` 固定铺满视口，图的 `50% 38%` 对齐视口的 `50% 38%`，图外用 `--edge` 补色。

| 位置 | 内容 |
| --- | --- |
| 四周 | 树林，错位成行，林下压一层深色 |
| 中上 | 小屋（红瓦木墙）、井、木桶、路牌 |
| 右上 | 谷仓、围栏、牲口 |
| 左下 | 菜地，四条垄，一圈栅栏 |
| 右下 | 池塘，沙岸 |
| 中间 | 石板路从屋门往下，岔一条去池塘 |

季节按访客当地的月份自动定：3–5 春，6–8 夏，9–11 秋，12–2 冬。季节只改颜色和少数物件，界面颜色不跟着变：

| 季 | 草 | 树 | 菜地 | 其他 |
| --- | --- | --- | --- | --- |
| 春 | 嫩绿，小花多 | 两种绿 | 出苗 | 蜂箱 |
| 夏 | 深绿 | 深绿、黄绿 | 结果 | 向日葵、睡莲 |
| 秋 | 黄褐 | 橙、金，松树仍绿 | 麦子、枯秆 | 蘑菇、落叶 |
| 冬 | 雪 | 雪树、常青 | 空垄 | 牲口进棚、冰面、谷仓顶积雪 |

天色按访客当地的钟点，在世界上盖一层半透明色，界面不变：

| 钟点 | `data-phase` | 世界 |
| --- | --- | --- |
| 5–7 | `dawn` | 偏暖 |
| 7–17 | `day` | 原色 |
| 17–19 | `dusk` | 偏红 |
| 19–5 | `night` | 压一层蓝 |

首页的世界只有天色；内页再盖一层 `--dim`，像游戏里打开菜单时一样。

## 6. 字

- 只用方舟像素 12px（比例宽度、简中）这一个文件，`font-display: block`，并在 `<head>` 预加载。不用衬线，不用外部字体服务。
- 字号只用 12 的整数倍：宽屏正文 24px，标题 36px；页签字、页脚声明、物品栏注释 12px。
- 窄屏（≤ 640px）正文 16px、标题 24px；2 倍屏上正文 18px。这两个值在 3 倍屏、2 倍屏上，每个字像素正好落在整数个物理像素上。
- 行高 1.5。不加字距。`-webkit-font-smoothing: none`。
- 昵称写 `Ricardo`，和中文之间空一格：「我是 Ricardo。」

## 7. 界面

### 右上角面板 `.hud`

```
╔══════════════════════════════╗
║ ┌──────────┐  10月2日 周五     ║
║ │ ☾ · ·    │  凌晨 2:36  ❀春  ║
║ │▔▔▔▔▔▔▔▔▔▔│                  ║
╚══════════════════════════════╝
```

- 左边一块小天窗：天的颜色跟着钟点（清晨、白天、傍晚、夜里四种分层色），太阳 5 点从左边升起、19 点在右边落下，沿弧线走；夜里换月亮和几颗星。底下一条当季颜色的草。
- 右边两行：日期和星期；钟点（凌晨、上午、中午、下午、晚上 + 12 小时制）。每 30 秒更新一次。
- 钟点后面是季节小牌：季节图标加一个字。它就是换季按钮，但不画按钮框，只在悬停时加底色。

### 对话框（首页）

```
╔═ 木框，里面上浅下橙 ═══════════════╗   ╔══════╗
║ 你好，我是 Ricardo。〔一句话介绍〕   ║   ║ 肖像 ║
║    你是做什么的？           关于    ║   ╚══════╝
║  ▶ 最近在忙什么？           近况    ║   〔Ricardo〕
║    ……                              ║
╚════════════════════════════════════╝
```

- 左正文，右肖像，名字写在肖像下面的纸卷上。
- 正文一两句，打字机出字。选项是访客的问话，右边小字是栏目名，两种读者都看得懂。
- 悬停或聚焦时整行加深，左边出箭头。
- 窄屏藏起肖像，名字纸卷压在对话框上沿。

### 菜单窗（内页，参照物品栏）

```
 [屋][历][箱][书][信][板]                                 ╳
 关于 近况 作品 笔记 联系 告示牌
╔═════════════════════════════════════════════════════════╗
║   ▢ ▢ ▢ ▢ ▢ ▢ ▢ ▢ ▢ ▢ ▢ ▢        ← 一排格子               ║
╠═════════════════════════════════════════════════════════╣ ← 木条
║ ╔══════╗  〔进来吧。椅子还有空。〕                        ║
║ ║ 肖像 ║  〔我是谁        ……〕                            ║
║ ╚══════╝  〔现在做什么    ……〕                            ║
║ 〔Ricardo〕〔不忙的时候    ……〕                            ║
╠═════════════════════════════════════════════════════════╣
║ 履历                                                     ║
║ 〔2026  一句〕                                            ║
╚═════════════════════════════════════════════════════════╝
```

- 菜单底 `--menu`，木框 `ui-menu.png`，边宽 8。最宽 320 美术像素。
- 页签是方块：图标在上，12px 的栏目名在下。当前页签亮色、下移 3 像素压住边框；其余暗一档。窄屏照样带图标。
- 右上角红叉压住框角，链回农场。
- 内容用木条 `.divider` 分成几段，木条两头压进木框里，像物品栏里那道横梁。
- 格子 `.slot` 比菜单底浅，细边，内凹。一排 12 格，窄屏 6 格一排。空格子就空着，不放假东西。
- 一条一行的东西放进凹格 `.row`，左边浅色的键，右边值。
- 物品提示框（作品页、随身物品用）：缩小的同一套木框，第一行名字，第二行浅色类别，第三行一句说明。悬停或聚焦格子时从格子下方弹出；靠两头的格子往里靠，不出框。
- 小木牌按钮 `.btn`：木边浅面，按下时变暗下沉一像素，禁用时褪成灰褐。
- 状态标签 `.tag`：深色细边加底色，金是进行中或未完成，红是卡住，绿是完成，灰褐是搁置。字一定写出来。
- 空状态放在一个凹格 `.empty` 里，字居中、浅色。

### 信纸（联系、笔记正文）

- 没有木框。浅奶油纸 `#ffefc9`，纸边是 `ui-letter.png` 的毛边，纸面铺 `paper-grain.png` 的细纤维，底下一道实色错位投影。字仍是深棕像素字。
- 用在 `/contact` 和 `/notes/` 下的正文页。
- 页签和红叉照旧，只是窗换成了纸。署名靠右。

### 告示牌（`/board`，本人自用）

参照的是农场小镇杂货铺门口那块告示牌：一块木板，左边钉一张当季月历，今天框出来、过去的日子发灰，有事的日子画上记号；右边钉委托单，单子上写着还剩几天。本站照这个意思重画，不用游戏的图。

- 窗是 `.board`：`ui-board.png` 的木框（同一种木头，最里一圈收深），里面平铺 `board-planks.png` 的横木板。直接写在木板上的字（标题、同步状态、分组名、抽屉名）用 `--cream` 加一像素实色错位阴影，焦点框也换成 `--cream`。
- 纸 `.sheet`：信纸同一种毛边和纤维，顶上正中一颗灰图钉。钉一张、月历、钥匙说明都是这种纸。
- 输入框 `.field`：和格子一样的内凹 `ui-slot.png`，底色 `--slot`。
- 月历：七列格子，格子底 `#fff7e2`、细边 `#d9b57e`；过去的日子 `#ecdcbc`、字变浅；今天描 `--ink` 深框；点选的那天用 `--menu-deep`。标题左边是这个月的季节图标，左右两个箭头是对话箭头 `ui-pointer.png`，左边那个镜像。
- 便条 `.note`：小块纸，细边 `#c99a5a`，右下一道实色错位投影，顶上正中一颗图钉。图钉颜色跟急不急走：红逾期、橙今天、金三天内、绿以后、灰没定日子。倒数写在小标签 `.due` 里，底色同一套：`#f09a84`、`#ffb65c`、`#ffd34d`、`#c7e6a8`、`#d8ccb6`，字一定写出来。
- 便条左边一个小凹格，指上去露出 `ui-tick.png` 的勾。「改」「撕」是浅色字按钮，不画框。
- 屏幕底下的小字 `.toast`：页签同一种小木框，几秒后收起。

## 9. 动效和声音

| 动作 | 做法 |
| --- | --- |
| 换页 | 同源跨页过渡（`@view-transition`）。世界和右上角面板留在原地；内页之间菜单就地换内容、量高度；从农场进内页，对话框落下、菜单浮起，世界同时压暗；约 260ms |
| 首页打字 | 每字 30ms，同一次浏览只打一遍。点一下或按任意键出全文。打完才出选项 |
| 悬停 | 立即变色，不做过渡 |
| 换季 | 立即换图 |

不支持跨页过渡的浏览器照常换页。`prefers-reduced-motion: reduce` 时不做过渡、不打字。没有声音，也不放声音开关。

## 10. 无障碍

- 焦点框 3 像素 `--focus`；压暗世界上的链接用 `--cream`。聚焦的页签浮到菜单上面，焦点框不被压住。只在 `:focus:not(:focus-visible)` 时去掉。
- 页签、选项、红叉都是真 `<a>`，写在每页 HTML 里。没有脚本时照样能走完全站，只少了打字、钟点和换季。
- 季节小牌是 `<button>`，`aria-label` 写清「现在是秋天，点一下换季」。
- 装饰图 `alt=""`。红叉有 `aria-label`。
- 状态不只靠颜色，一定写出「完成」「卡住」这类字。
