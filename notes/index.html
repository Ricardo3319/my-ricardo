同机架微秒级 RPC 调度研究（rpcsim）

针对 1 至 10 微秒极短任务下通信开销与服务时间同量级的调度难题，基于 C++17 构建 128 核机架级全链路纳秒显式计费仿真器（E0 与 M/M/k、M/G/1、M/H2/k 解析解 100% 置信对齐）。量化揭示了单机多核池化（8 核及以上）将跨机纠偏空间压缩至 0.4 个百分点以内、31 组高时延反噬反例，以及软件网关饱和断崖与 20% 算力预算下 79.2% 配置无解的资源红线。

my-ricardo 像素农场个人站与随身工作台

零前端框架依赖的个人赛博木屋：由 Python 逐像素生成四季农场与碰撞位图，内置 Web Audio 实时合成田园音乐、4 倍超采样像素互动小程序（池塘垂钓、矿车历险、农田番茄钟、古井祈愿签），以及支持自建 SQLite 云端与 GitHub 仓库降级同步的跨设备告示牌与剪贴板。
